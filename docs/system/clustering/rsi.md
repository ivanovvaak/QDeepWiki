# RSI

**Идея.** Заказы обрабатываются по одному, и каждый вставляется в существующую группу или открывает новую.

## Как работает

1. Порядок обработки фиксируется для каждого варианта: заказы сортируются по времени готовности, к каждому времени добавляется независимый шум, равномерно распределённый на \([-2, 2]\) минуты. Варианты примерно совпадают в последовательности поступления заказов, но по-разному упорядочивают заказы, ставшие готовыми почти одновременно.
2. Для каждого заказа проверяются все существующие группы. Добавить заказ можно, только если итоговая масса не превышает вместимость наименьшего типа транспорта, способного её увезти.
3. Среди подходящих групп заказ вставляется в ту, чей центр ближе всего (по евклидову расстоянию). Центр — среднее координат текущих заказов группы; он пересчитывается заново при каждой проверке.
4. Если ни одна группа не может принять заказ, открывается новая группа из одного этого заказа.

Группы растут до общего потолка 40 кг с тем же механизмом повышения типа транспорта, что и в других алгоритмах.

## Параметры

Каждый вариант использует свой номер (seed) 0, 1, …, n−1, от которого зависят шум во времени готовности и итоговый порядок вставки. В отличие от остальных четырёх алгоритмов, сетки параметров нет.

## Ограничение

Единственный критерий вставки — расстояние до центра группы. Алгоритм не сравнивает стоимость открытия новой группы со стоимостью вставки в существующую, а проверяет только, подходит ли существующая группа по массе.

??? note "Псевдокод"
    ```
    procedure RSI(orders, depot, seed)
        sorted ← sort orders by ready(o) + uniform(−2, 2), using seed
        clusters ← ∅
        for each order o in sorted do
            best ← null; best_dist ← ∞
            for each cluster c in clusters do
                M ← mass(c) + weight(o)
                σ ← smallest courier type with capacity ≥ M
                if M > capacity(σ) then
                    continue
                end if
                (cx, cy) ← centroid of c's orders
                dist ← euclidean(o, (cx, cy))
                if dist < best_dist then
                    best_dist ← dist; best ← c
                end if
            end for
            if best ≠ null then
                add o to best; retype best by its new mass
            else
                open a new singleton cluster {o}
            end if
        end for
        return clusters
    end procedure
    ```
