# Sweep

**Идея.** Заказы группируются по направлению от склада: заказы, лежащие в одном направлении, могут разумно делить одну поездку, а заказы с противоположных сторон склада лучше обслуживать отдельно.

## Как работает

1. Заказы обходятся по углу относительно склада, начиная со стартового угла θ₀.
2. Группу открывает первый заказ в этом порядке.
3. Следующие заказы добавляются, пока выполняются оба условия:
    - угловое отклонение заказа от **первого заказа группы** не больше порога Δmax;
    - масса группы вместе с новым заказом не превышает вместимость наименьшего типа транспорта, способного её увезти.
4. Как только условие нарушено, группа закрывается, и новая начинается с заказа, нарушившего условие. Закрытой группе присваивается наименьший тип транспорта, вмещающий её массу.

Угловой порог отсчитывается от первого заказа группы, а не от фиксированного направления, поэтому группы получаются узкими и закрываются раньше, чем этого требует вместимость.

Группа может расти до вместимости самого вместительного типа транспорта (40 кг) независимо от того, есть ли курьер такого типа в парке: это проверяется отдельно, после генерации вариантов.

## Параметры и разнообразие вариантов

- Стартовые углы детерминированы и распределены равномерно: i-й из n вариантов начинается с угла

    $$
    \theta_0 = \frac{2\pi i}{n}
    $$

- Порог Δmax выбирается для каждого варианта независимо из значений 30°, 45°, 60°, 90°, 120°.
- Поскольку стартовый угол задан номером варианта, разнообразие вариантов создаёт только угловой порог.

??? note "Псевдокод"
    ```
    procedure Sweep(orders, depot, N)
        for i ← 0 to N − 1 do
            θ0 ← 2πi/N                                ▷ evenly spaced start angle
            Δmax ← random choice from {30°, 45°, 60°, 90°, 120°}
            sort orders by polar angle relative to depot, starting from θ0
            C ← ∅; θ1 ← null                          ▷ C: current cluster, θ1: its first order's angle
            for each order o in sorted order do
                if C = ∅ then
                    C ← {o}; θ1 ← θ(o)
                else
                    d ← angular distance(θ(o), θ1)
                    M ← mass(C) + weight(o)
                    σ ← smallest courier type with capacity ≥ M
                    feasible ← (d ≤ Δmax) and (M ≤ capacity(σ))
                    if feasible then
                        add o to C
                    else
                        close C                       ▷ type = smallest type fitting mass(C)
                        C ← {o}; θ1 ← θ(o)
                    end if
                end if
            end for
            close final C; add partition to pool
        end for
    end procedure
    ```
