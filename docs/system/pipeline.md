# Конвейер решения

Конвейер получает текущие заказы, доступных курьеров и склады и выдаёт план доставки.

Совместный выбор группировки заказов, порядка доставки и назначения курьеров — NP-трудная задача: при реальных объёмах заказов точное решение вычислительно недостижимо. Поэтому используется подход «сначала кластеризация, потом маршрутизация» (cluster-first, route-second): сначала заказы группируются в поездки, и только затем для каждой поездки определяется порядок доставки.

## Этапы

**1. Кластеризация.** Каждый из пяти алгоритмов — [Sweep](clustering/sweep.md), [Clarke-Wright](clustering/clarke-wright.md), [DBSCAN](clustering/dbscan.md), [Adaptive DBSCAN](clustering/adaptive-dbscan.md), [RSI](clustering/rsi.md) — создаёт набор вариантов разбиения заказов на группы. У каждого алгоритма есть параметры, и их изменение между запусками делает набор вариантов разнообразнее. Каждый вариант проверяется на выполнимость: масса поездки в пределах вместимости, в парке есть курьер подходящего типа транспорта. Невыполнимые варианты отбрасываются.

**2. Маршрутизация.** Внутри каждой группы определяется порядок доставки: решается небольшая задача коммивояжёра.

**3. Назначение поездок курьерам.** Каждая поездка назначается самому дешёвому доступному курьеру. Стоимость курьера зависит от того, когда он освободится от текущей поездки и сколько ему добираться до склада поездки.

**4. Выбор плана.** Из вариантов, давших полностью выполнимый план, выбирается самый дешёвый.

**5. Локальный поиск.** Выбранный план пытаются улучшить локальными изменениями: перенести заказ из одной поездки в другую, объединить две поездки или разделить одну поездку на несколько.

Подробнее об этапах 2 и 3 — на странице [Маршрутизация и назначение курьеров](routing.md).

## Общие правила для алгоритмов кластеризации

- Все заказы одной поездки — с одного склада.
- При кластеризации учитывается вместимость разных типов транспорта. Группа заказов может расти до вместимости самого вместительного типа (автомобиля, 40 кг); по итогу ей присваивается наименьший тип транспорта, вместимость которого достаточна для её массы.
- Есть ли курьер нужного типа транспорта в парке, проверяется после кластеризации.
- Количество поездок заранее не задаётся. Оно определяется географией заказов, вместимостью и, для методов вставки, порядком обработки заказов.
