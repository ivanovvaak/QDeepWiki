# Модель данных

## Входные сущности

В планировании участвуют пять сущностей.

| Сущность | Структура | Атрибуты |
| --- | --- | --- |
| Заказ | `orders: List[Order]` | Координаты адреса доставки, масса, склад отгрузки, время готовности, срок доставки |
| Курьер | `couriers: List[Courier]` | Тип, скорость, вместимость, начальная позиция |
| Склад | `warehouses: List[Warehouse]` | Координаты |
| Тарификация | `tariffication: Tariffication` | Тарифные коэффициенты по типам курьеров и штраф за опоздание ([модель стоимости](../requirements/business-rules.md#модель-стоимости)) |
| Ограничения | `constraints: Constraint` | Параметры ограничений планирования; состав уточняется |

## Результат планирования

Результат планирования содержит:

- поездки — склад, тип курьера, упорядоченный список заказов, время отправления;
- назначение поездок курьерам и последовательность поездок каждого курьера;
- заказы, требующие дополнительных ресурсов.

Результат сохраняется и отображается пользователю. Форматы и протоколы обмена с системами Заказчика необходимо согласовать.
