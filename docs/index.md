## Кратко о проекте

Проект решает задачу оперативной доставки для заказчика. Заказы поступают непрерывно, и каждые несколько секунд система решает, какие заказы объединить в одну поездку, в каком порядке их развезти и какому курьеру отдать: пешему, велосипедисту или на автомобиле. Цель — чтобы доставка обходилась как можно дешевле и без опозданий.

Решение устроено как конвейер: сначала заказы группируются в поездки, затем для каждой поездки строится маршрут и подбирается курьер, после чего лучший план дополнительно улучшается. Главный исследовательский вопрос — какой алгоритм группировки заказов лучше работает и в каких условиях. Для этого результаты алгоритмов сравниваются с идеальными решениями, которые находит точный решатель.
